# DevSecOps Track: Weekly Checklist

## M7 Track Lab (weeks 13-14)

- [ ] Create your codespace and confirm `bash scripts/run_tests.sh` passes
- [ ] Add `migrations/V004__...sql` that adds one new feature (for example, a `review` table)
- [ ] Add at least 2 tests for your new feature in `tests/`
- [ ] Push and confirm all 3 pipeline jobs are green
- [ ] Break a test on purpose, push, and screenshot the red pipeline; then fix it

## M8 + Capstone (weeks 15-16)

- [ ] Add an audit trigger migration that logs changes to `customer`
- [ ] Add a test that proves the trigger writes to the audit table
- [ ] Fill in every STUDENT section of README.md
- [ ] Record a 3-5 minute demo: codespace, a migration, the pipeline, one security choice
- [ ] Create release `v1.0` on GitHub
